### 💸 Expense Management System

A full-stack web application to track income, expenses, categories, payment methods and monthly budgets.

- Implemented complete CRUD workflows with Entity Framework Core and SQL Server across all financial entities.
- Enforced user-specific data access so each user views and manages only their own records.
- Built a dashboard that summarizes balances, spending and budget progress.

### 🗳️ Online Voting Application

A Java web application for voter registration, candidate selection and vote confirmation.

- Built the registration, voting and results pages with Servlets and JSP.
- Implemented server-side age-based eligibility validation that blocks ineligible voters and shows clear error messages.
- Processed form submissions through Servlets and stored voter and vote records in MySQL via JDBC.

| Layer | Technology |
| --- | --- |
| Language | Java |
| Web | Servlets, JSP |
| Data Access | JDBC |
| Database | MySQL |
